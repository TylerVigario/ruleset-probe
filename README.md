# ruleset-probe

Scratch repository. It exists to test, by attempt, how GitHub rulesets behave,
so the repository standard states what GitHub does rather than what its
documentation implies.

Every tag here was pushed at a rule on purpose, and the tag rulesets make them
undeletable. The releases here were published only to test immutable releases
and attestations; none is a release of anything.

The second commit exists so a tag can be moved between two commits.
